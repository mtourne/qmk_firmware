MT Custom K11 Max
=======================

Main
=====
* Space func implement by holding space bar
* Caps is LCTL
* Added an ESC below DEL key
* Added another ESC above Fn2 where an extra right-hand B was,
  This is not proving to be too useful.
  (experimenting with tap dance GRV-ESC)



Experimental
================
* Grave key (`~) is by default,
   and a short double tap (175ms) makes an ESC
